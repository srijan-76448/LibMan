# LibMan

A lightweight Library Management System designed for efficient book inventory tracking, user records management, and automated transaction logging. 

## Features

- **Inventory Tracking:** Real-time monitoring of available, issued, and reserved books.
- **Member Management:** Comprehensive registry for user profiles, borrowing history, and fine tracking.
- **Transaction Engine:** Seamless issue and return processing with automated due-date calculations.
- **Search Optimization:** Fast querying mechanisms by title, author, ISBN, or category.
